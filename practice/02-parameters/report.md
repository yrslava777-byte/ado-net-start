## 2. Обычные поисковые строки

`мыши` находит один товар, `мыш` находит два. В исходной программе апостроф в имени `D'Artagnan` приводит к синтаксической ошибке 42601, потому что ввод вставляется в SQL.

## 4. Исправление SearchApp

Поиск использует `ILIKE @pattern`. Шаблон с символами `%` передаётся отдельным параметром. После исправления проверено на учебной базе PostgreSQL: `USB` находит USB-хаб, `D'Artagnan` даёт 0 результатов без ошибки, `мыш` находит 2 товара.

Фактический вывод исправленной программы при поиске USB:

```text
Поиск товара: SQL: SELECT id, name, price FROM products WHERE name ILIKE @pattern ORDER BY id
7: USB-хаб, 1190,00 руб.
Найдено товаров: 1
```
